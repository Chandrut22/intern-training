# Large Language Models (LLMs) 101

Below is a “cheat‑sheet” that covers the basics you need to know:

| Topic | What it means | Key points / examples |
|-------|---------------|-----------------------|
| **What is a “large” language model?** | A neural network that has been trained on *billions* of tokens (words, sub‑words, or characters) and contains millions or billions of learnable parameters. The “large” part refers to the scale – the more parameters, the more complex patterns it can learn. | • GPT‑3 (175 B parameters) <br>• LLaMA‑2 70 B <br>• PaLM‑2 540 B <br>• GPT‑4 (estimated > 200 B) |
| **Core idea** | The model learns statistical regularities of language: word co‑occurrence, syntax, semantics, world knowledge, etc. Once trained, it can **predict** what comes next (or fill in a missing part) almost as if it had “understood” the text. | • Language modeling loss → cross‑entropy between predicted and real token.<br>• Training is unsupervised or self‑supervised (no manual labels). |
| **Training data** | Usually a massive, diverse web corpus: Wikipedia, Common Crawl, books, code repositories, news, etc. Cleaned and tokenized. | • Tokenization: WordPiece, Byte‑Pair Encoding (BPE), SentencePiece, etc. <br>• Context window: 2048, 4096, or even 32k tokens in newer models. |
| **Main architectures** | 1. **Autoregressive (AR)** – generates one token at a time conditioning on the previous tokens. <br>2. **Masked Language Model (MLM)** – predicts missing tokens in a masked sentence (used for embeddings, downstream tasks). <br>3. **Encoder–Decoder (Seq2Seq)** – jointly learns to encode an input text and generate an output (translators, summarizers). <br>4. **Multi‑modal** – extends beyond text (e.g., CLIP, DALL‑E, GPT‑4Vision). | • **AR**: GPT series, LLaMA, Gemini.<br>• **MLM**: BERT, RoBERTa, DeBERTa, Longformer.<br>• **Seq2Seq**: T5, BART, mT5.<br>• **Multi‑modal**: Vision‑Encoder‑Decoder (ViT‑BART), GPT‑4V, PaLM‑E. |
| **How they learn** | 1. **Self‑supervised pre‑training** → train on raw text.<br>2. **Fine‑tuning** → adapt to a specific downstream task with a smaller dataset (SFT = supervised fine‑tune).<br>3. **Reinforcement Learning from Human Feedback (RLHF)** → fine‑tune with reward models derived from human preferences (e.g., GPT‑4, Claude). | • “Instruction fine‑tuning” (OpenAI’s “InstructGPT”) is a popular RLHF variant.<br>• The reward model can be any differentiable loss derived from human ranking. |
| **Key performance metrics** | • Perplexity (lower is better). <br>• Accuracy on downstream tasks (GLUE, SQuAD, etc.).<br>• Few‑shot / in‑context learning ability. <br>• Zero‑shot generalization. | • The 175 B GPT‑3 has ~55 B context‑window; LLaMA‑2 70 B gets 90 % accuracy on many tasks without fine‑tuning. |
